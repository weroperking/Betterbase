# Blog Template

A BetterBase **content/blog starter**. Built on the IaC-first structure with
`posts`, `tags`, `post_tags` (join), and `comments`.

## What's included

- Schema with a full-text `searchIndex` on post content.
- Queries: `listPosts`, `getPost` (by slug), `listByTag`, `listComments`, `searchPosts`.
- Mutations: `createPost`, `addComment`, `tagPost`.

## Running

```bash
# 1. Scaffold into a new project
mkdir my-blog && cd my-blog
cp -r <repo>/templates/blog/* .

# (The real `bb init --template blog` is coming; for now copy manually.)

# 2. Configure environment
export DATABASE_URL="postgresql://user:pass@localhost:5432/myblog"

# 3. Install and sync
bb deps install
bb iac sync

# 4. Run
bb dev
```

## Example client call

```bash
curl -X POST http://localhost:3000/betterbase/queries/posts/getPost \
  -H "Content-Type: application/json" \
  -d '{ "args": { "slug": "hello-world" } }'
```

## Notes

- Do not edit `betterbase/_generated/*` — regenerated by `bb iac sync`.
