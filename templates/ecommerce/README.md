# E-commerce Template

A BetterBase **e-commerce starter**. Built on the IaC-first structure with
`products`, `carts`, `cart_items`, `orders`, and `order_items`.

## What's included

- Products catalog with a full-text `searchIndex` on name and SKU indexes.
- Cart operations: `getCart`, `addToCart`.
- Checkout: `checkout` converts a cart into an order + order items.
- Storefront queries: `browseProducts`, `getProduct`, `getOrder`, `searchProducts`.
- A `createProduct` mutation for catalog management.

## Running

```bash
# 1. Scaffold into a new project
mkdir my-shop && cd my-shop
cp -r <repo>/templates/ecommerce/* .

# (The real `bb init --template ecommerce` is coming; for now copy manually.)

# 2. Configure environment
export DATABASE_URL="postgresql://user:pass@localhost:5432/myshop"
export STRIPE_SECRET_KEY="sk_live_..."   # for the billing action only

# 3. Install and sync
bb deps install
bb iac sync

# 4. Run
bb dev
```

## Payments

Amounts are stored in **cents** (`priceCents`, `totalCents`) to avoid float
issues. The Stripe secret key is **never stored** in the schema — your billing
`action` reads `STRIPE_SECRET_KEY` from the environment and stores only the
resulting `stripePaymentIntentId` on the order.

## Notes

- Do not edit `betterbase/_generated/*` — regenerated by `bb iac sync`.
