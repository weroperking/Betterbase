# Realtime Template

A BetterBase **WebSocket/realtime** focused project. Built on the IaC-first
structure with a realtime-friendly schema: `rooms`, `messages`, `presence`.

Writes through `ctx.db` automatically emit table-change events that push to
subscribed clients. The `messages` and `presence` tables are the realtime
surface; client subscriptions live in `@betterbase/client` (`packages/client/src/iac/`).

## What's included

- `rooms` / `messages` / `presence` tables with indexes for fast room-scoped reads.
- Queries: `listRooms`, `listMessages`, `listPresence`.
- Mutations: `createRoom`, `sendMessage`, `updatePresence`.

## Subscribing on the client (vanilla)

```typescript
import { createBetterBaseClient } from "@betterbase/client/iac";
import { api } from "./betterbase/_generated/api";

const client = createBetterBaseClient({ url: "http://localhost:3000" });

// Subscribe to new messages in a room — fires onChange on every insert.
const unsubscribe = client.subscribe(
  api.queries.rooms.listMessages,
  { roomId: "<room-id>" },
  () => {
    client.query(api.queries.rooms.listMessages, { roomId: "<room-id>" })
      .then((messages) => console.log("updated", messages));
  },
);

// Later:
unsubscribe();
```

## Subscribing on the client (React)

```tsx
import { useQuery } from "@betterbase/client/iac";
import { api } from "./betterbase/_generated/api";

function Room({ roomId }: { roomId: string }) {
  const { data, isLoading } = useQuery(api.queries.rooms.listMessages, { roomId });
  // useQuery auto-subscribes via WebSocket and refetches on invalidation.
  if (isLoading) return <p>Loading…</p>;
  return <ul>{data?.map((m) => <li key={m._id}>{m.body}</li>)}</ul>;
}
```

When `sendMessage` runs server-side, the inserted row emits a change event and
the subscription above refetches automatically.
